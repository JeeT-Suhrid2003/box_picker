# models.py
from django.db import models

class BoxCategory(models.TextChoices):
    STANDARD = "STANDARD", "Standard Goods"
    FRAGILE = "FRAGILE", "Fragile / Glassware"
    APPAREL = "APPAREL", "Clothing / Soft Goods"
    HEAVY_DUTY = "HEAVY_DUTY", "Heavy Machinery / Tools"
    LIQUID = "LIQUID", "Bottles / Liquids"

class Box(models.Model):
    name = models.CharField(max_length=100)
    length = models.FloatField(help_text="Internal length in cm")
    width = models.FloatField(help_text="Internal width in cm")
    height = models.FloatField(help_text="Internal height in cm")
    max_weight = models.FloatField(help_text="Max weight capacity in kg")
    cost = models.DecimalField(max_digits=8, decimal_places=2)
    allowed_categories = models.JSONField(
        default=list, 
        help_text="List of compatible BoxCategory strings"
    )

    @property
    def volume(self):
        return self.length * self.width * self.height

class Product(models.Model):
    title = models.CharField(max_length=255)
    description = models.TextField(blank=True)
    length = models.FloatField(help_text="Length in cm")
    width = models.FloatField(help_text="Width in cm")
    height = models.FloatField(help_text="Height in cm")
    weight = models.FloatField(help_text="Weight in kg")
    category = models.CharField(
        max_length=50, 
        choices=BoxCategory.choices, 
        blank=True
    )
Step-by-Step Implementation Blueprint
1. Gemini Categorization Service

Create an isolated service module (services/ai_classifier.py).

Prompt Gemini with strict structured output (response_mime_type="application/json" or enum-constrained schema) containing only the valid values from BoxCategory.

Provide fallback logic: If the API call fails or times out, assign BoxCategory.STANDARD and log the error.

2. Product Creation & Override Endpoint (POST /api/products/)

Accepts product dimensions, weight, title, description, and optional category.

If category is supplied, use it directly (manual override).

If category is omitted, invoke the Gemini classification service.

Support a PATCH /api/products/{id}/ endpoint to manually reassign categories anytime.

3. Box Recommendation Engine (POST /api/recommend-box/)

Keep the final box selection deterministic rather than letting the LLM guess fit.

The algorithm takes a list of items and their quantities:

Calculate aggregate or bounding volume and total order weight.

Filter boxes where box.max_weight >= total_weight.

Filter boxes where product dimensions fit within (length, width, height) allowing for standard 3D rotations.

Ensure the box's allowed_categories contains the items' assigned categories.

Select the matching box with the lowest cost.
